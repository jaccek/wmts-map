# Compose components and design system

- **MUST** use approved design-system tokens for colors, typography, shapes and spacing.
- **MUST** reuse existing components before creating a new component with overlapping purpose.
- **SHOULD** design reusable components around semantic parameters rather than exposing every low-level styling option.
- **SHOULD** provide accessibility semantics, meaningful labels and appropriate touch targets.
- **SHOULD** preview components where the project tooling supports previews.
- **MUST** avoid hard-coded colors, dimensions and typography when a design token exists.
- **MUST** keep platform-specific behavior explicit rather than hiding it in a supposedly universal component.

Company decision required: identify the design-system module, token source, component catalog and accessibility checklist.
